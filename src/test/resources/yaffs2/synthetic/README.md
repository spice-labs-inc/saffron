# Synthetic YAFFS2 samples

20 synthetically generated YAFFS2 images covering the geometry/endianness
matrix and object-type mix. No third-party content is embedded: file
contents are trivial text patterns generated by the script itself.
Regenerate with `src/test/resources/yaffs2/generate-synthetic.sh` (Docker;
one-time). Built with the reference `mkyaffs2image` from the YAFFS2 source
(Aleph One, GPL-2.0).

| Sample | Geometry | Endianness | Notes |
|--------|----------|------------|-------|
| synth-2048-64-tree-le.yaffs2 | 2048/64 | LE | dirs, files, symlink, hardlink, empty file |
| synth-2048-64-tree-be.yaffs2 | 2048/64 | BE | same tree, big-endian |
| synth-2048-64-empty-dir-le.yaffs2 | 2048/64 | LE | directory with one empty file |
| synth-2048-64-devices-le.yaffs2 | 2048/64 | LE | char/block/fifo device nodes |

Note: the reference tool writes tags with a serial number in the low 16
bits of every field (value << 16 | serial); Saffron normalizes both that
form and the plain form. The synthetic set therefore exercises the
shifted-serial encoding end-to-end.
