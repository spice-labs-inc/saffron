# Synthetic UBIFS / UBI samples

13 synthetically generated samples built with the reference `mkfs.ubifs` /
`ubinize` (mtd-utils). No third-party content is embedded: file contents are
trivial text patterns generated by the script itself. Regenerate with
`src/test/resources/ubifs/generate-synthetic.sh` (Docker; one-time).

| Sample | Kind | Variant |
|--------|------|---------|
| synth-zlib-124k.ubifs | UBIFS | zlib compression, LEB 124 KiB (min-io 2048) |
| synth-none-124k.ubifs | UBIFS | no compression |
| synth-lzo-124k.ubifs | UBIFS | LZO compression |
| synth-zstd-124k.ubifs | UBIFS | ZSTD compression |
| synth-zlib-248k.ubifs | UBIFS | LEB 248 KiB (min-io 4096) |
| synth-zlib-62k.ubifs | UBIFS | LEB 62 KiB |
| synth-zlib-31k.ubifs | UBIFS | LEB 30 KiB |
| synth-zlib-15k.ubifs | UBIFS | minimum LEB 15.5 KiB (min-io 512) |
| synth-empty.ubifs | UBIFS | empty filesystem |
| synth-single.ubifs | UBIFS | single file |
| synth-two-vol.ubi | UBI | two volumes (zlib + none), PEB 128 KiB |
| synth-two-vol-248k.ubi | UBI | two volumes, PEB 256 KiB |
| synth-two-vol-truncated.ubi | UBI | truncated final PEB (partial dump) |

Additional fixtures under `src/test/resources/ubifs/fixtures/`:
`tree-{zlib,none,lzo,zstd}.ubifs` (round-trip tests) and `two-vol.ubi`.

Note: the tiny-PEB UBI variant (2048-byte PEBs, as in unblob's fruits.ubi)
cannot be produced by ubinize; real-world coverage of that geometry comes
from the wild corpus (`fruits.ubi`).
