# Synthetic cramfs samples

23 synthetically generated cramfs images covering the format's variant
axes. No third-party content is embedded: the file contents are trivial
text/binary patterns generated by the script itself. Regenerate with
`src/test/resources/cramfs/generate-synthetic.sh` (Docker; one-time).

| Sample | Toolchain | Variant |
|--------|-----------|---------|
| synth-ul-le-tree.cramfs | util-linux mkfs.cramfs 2.39 | LE, sorted dirs, symlink, compressible + sparse files |
| synth-ul-be-tree.cramfs | util-linux + cramfsswap | big-endian |
| synth-ul-holes.cramfs | util-linux `-z` | explicit holes |
| synth-ul-incompressible.cramfs | util-linux | uncompressed blocks (incompressible data) |
| synth-ul-deep.cramfs | util-linux | 8-level nesting, 240-char names, 300 files |
| synth-ul-empty.cramfs | util-linux | empty filesystem |
| synth-np-tree.cramfs | npitre/cramfs-tools (2018) | LE tree |
| synth-np-be.cramfs | npitre `-B` | native big-endian output |
| synth-np-holes.cramfs | npitre `-z` | explicit holes |
| synth-np-incompressible.cramfs | npitre | uncompressed blocks |
| synth-np-devices.cramfs | npitre `-D` devtable | char/block/fifo device nodes |
| synth-np-padded-512.cramfs | npitre `-p` | 512-byte boot-code padding |
| synth-np-extptr.cramfs | npitre `-x` | extended block pointers |
| synth-lzma-4k.cramfs | OpenRG mkcramfs-lzma (Actiontec GPL) | LZMA blocks, 4 KiB |
| synth-lzma-16k.cramfs | OpenRG mkcramfs-lzma | LZMA blocks, 16 KiB |
| synth-lzma-32k.cramfs | OpenRG mkcramfs-lzma | LZMA blocks, 32 KiB |
| synth-lzma-64k.cramfs | OpenRG mkcramfs-lzma | LZMA blocks, 64 KiB (classic router config) |
| synth-openrg-gzip-64k.cramfs | OpenRG mkcramfs-lzma `-c gzip` | OpenRG flags with zlib blocks, 64 KiB |
| synth-openrg-none-64k.cramfs | OpenRG mkcramfs-lzma `-c none` | OpenRG flags, uncompressed, 64 KiB |
| synth-wrong-signature.cramfs | patched util-linux image | WRONG_SIGNATURE flag + mangled signature |
| synth-unsorted.cramfs | patched util-linux image | SORTED_DIRS cleared |
| synth-fsid-v1.cramfs | patched util-linux image | FSID_V2 cleared, size field zero |
| synth-shifted-512.cramfs | patched util-linux image | 512-byte prefix, all offsets +512, SHIFTED_ROOT_OFFSET |

Known limitation: content reads of the OpenRG samples (LZMA compression or
non-4096 block sizes) are not yet supported by Saffron; detection, mount,
and walk work. See docs/cramfs.md.
